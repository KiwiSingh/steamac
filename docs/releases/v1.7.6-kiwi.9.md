# Steamac 1.7.6 Kiwi Build 9

Pairs with [BepisLoader 2.3.4](https://github.com/KiwiSingh/BepisLoader/releases/tag/v2.3.4).

- **Discord Rich Presence for Steam Games**: Automatically announces the focused Steam game on Discord via native macOS Discord IPC (supporting official Discord and Vesktop/arRPC), with persistent socket lifecycle management, Steam CDN game assets, and verified Steam application ID metadata.
- **In-Launcher GE-Proton Downloader**: Added automated fetching and installation of the latest upstream GE-Proton compatibility runtime tarballs directly into `~/.local/share/Steam/compatibilitytools.d/` through the settings interface and SSH bridge.
- **BepisBridge & Cockpit Reliability**: Updated launch options and guest communication protocols for synchronized Proton prefix discovery and robust mod injection.
- **Packaging and License Build Fixes**: Fixed `licenses.sh` and bundling tooling to ensure reproducible ad-hoc signing and packaging.

Quit the VM normally before replacing Steamac, then restart it using this release's bundled layer. No disk recreation is required. Close the game before installation or Apply; Steam may remain open.

Validation: App bundle audit passed; ad-hoc codesigning verified across all Mach-O binaries; Discord IPC socket persistence verified with arRPC and native clients; GE-Proton automated installation verified.
