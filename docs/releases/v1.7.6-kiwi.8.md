# Steamac 1.7.6 Kiwi Build 8

Pairs with [BepisLoader 2.3.1](https://github.com/KiwiSingh/BepisLoader/releases/tag/v2.3.1).

- Adds checked, game-agnostic x64 DXGI ReShade installation, runtime discovery and saved installed state through the existing Bepis bridge.
- Enables automatic official runtime/compiler setup from BepisLoader, preset/shader/addon package installation, and explicit backup-and-replace of ReShade.ini.
- Supports 1 GiB mod packages/combined profiles and 128 MiB files, with the matching native adapter and table/music compiler.
- Adds guest-side profile composition: existing mod payloads remain in the VM. Reuses verified compiled tables/music from the previous active profile when compiler, original game data and ordered inputs match. Unchanged profiles retain the active snapshot.
- Preserves source/output validation, conflict priority, game-closed checks, rollback and atomic activation.

Quit the VM normally before replacing Steamac, then restart it using this release's bundled layer. No disk recreation is required. Close the game before installation or Apply; Steam may remain open. Copy BepisLoader's combined launch options manually into Steam and preserve other settings/arguments. ReShade and asset loaders use one combined WINEDLLOVERRIDES assignment.

Validation: app-bundle audit passed; 72 ARM64 Bepis-agent tests, 50 progress-agent tests, MBE/music/cache self-tests, host metadata-only Apply/older-guest fallback and exact 1 GiB/128 MiB boundaries. ARM64 and x64 CI checks passed. Performance improvements are verified by transfer/cache regression checks; live end-to-end timing has not been measured.

The release ZIP is ad-hoc signed, not notarized. Components were signed individually and the bundle verified strictly; codesign --deep was not used. Corresponding GPL sources and SHA256SUMS are attached to the release.
