# Steamac 1.7.6 Kiwi Build 5 — BepisLoader Asset Mods

Adds `assetModInstallV1` to the bundled ARM64 SteamOS guest agent for [BepisLoader 2.1.0](https://github.com/KiwiSingh/BepisLoader/releases/tag/v2.1.0). The checked asset-only adapter supports the pinned x64 Digimon Story Time Stranger build under Proton. Green-eye texture replacement was confirmed in live gameplay; arbitrary managed mods remain outside this validation.

## Updating and using mods

- Quit the VM normally, replace the Steamac app, then restart using its bundled guest layer. Existing SteamOS disks, games and saves can be retained; no disk recreation is required. If using custom guest-layer paths, select the new bundled layer.
- Close the game while installing or disabling asset mods. Steam can remain open.
- Manually copy the exact launch setting from BepisLoader's installation report into Steam → game Properties → Launch Options, preserving compatible existing options.
- Unsupported game/payload hashes, executable mod packages, unsafe paths and conflicting loader files fail closed. Disabling parks the checked adapter and retains assets.

Retains Kiwi Build 4's bridge-status fixes and current bounded recovery-inventory work. Rebuilds the static ARM64 guest agents and guest layer plus the macOS ARM64 launcher. Kernel and graphics dependencies use validated existing build artifacts.

Signing is performed inside out, with individual component signatures and the app signed last. No `codesign --deep` is used. The ZIP is ad-hoc signed and not Developer ID notarized.

Based on [fxgl/steamac](https://github.com/fxgl/steamac), with Kiwi fork integration. Licenses and third-party notices are included in the app.

Asset publication preserves filenames and bytes, including raw `.img` files. No extension, texture-directory or DDS-header requirement is imposed. Relative-path containment, symlink, collision, hash and size checks remain.

## If BepisLoader still reports an unsupported guest

The app's version alone does not identify the agent running inside SteamOS. After updating, shut down the VM normally and restart it with this release's bundled layer. Custom layer paths and user service overrides can keep an older agent active.

In the SteamOS terminal, `systemctl --user show fx-bepis-agent -p ExecStart -p DropInPaths` should show `/usr/lib/steamac/fx-bepis-agent`. If it points to an older test agent in the home directory, review and archive that specific override outside `fx-bepis-agent.service.d`, then run `systemctl --user daemon-reload` and `systemctl --user restart fx-bepis-agent`. Do not remove unrelated overrides. Refresh BepisLoader's connection and library afterward.
