# Steamac 1.7.6 Kiwi Build 6 — Combined Asset Profiles

Audited release: Steamac 1.7.6 Kiwi Build 6 (build 17607).

Adds assetModProfilesV1 for BepisLoader 2.2.0. The guest stores ordered package metadata with immutable merged asset snapshots and exposes a stable `.bepis-assets-active` path. It validates all referenced package bytes, recalculates conflict winners, refuses stale updates and activates the snapshot using checked atomic pointer publication. Earlier package installs are imported disabled for review; snapshots and removed packages are retained.

Update the app and restart the VM using its bundled guest layer. Old package-specific launch paths must be changed once to the stable setting reported by BepisLoader. Steam can remain open; close the game before applying profiles and restart it afterward. Empty profiles produce no replacements. Custom layers and old agent overrides can prevent the new capability from appearing; inspect the running fx-bepis-agent service when needed.

No game-build or loader-integrity gates are removed. The first supported adapter remains pinned to the verified x64 Digimon Story Time Stranger executable. This release does not add support for arbitrary games or managed mod loaders.

Individual components are signed inside out; no codesign --deep. Includes kernel/graphics artifacts with valid build receipts and a rebuilt static ARM64 guest agent/layer.

- Compile Media.Vision MBE CSV edits against original game tables, merge changed cells in profile order, append `.ap.csv` rows, and inject rebuilt MBE files. Ships a self-contained ARM64 compiler with MIT-licensed MVLibraryNET and pinned .NET/dependencies.
- Loader update resolves the stable profile folder before taking its immutable snapshot. Precisely pinned previous loaders are exchanged atomically and retained as backups; unknown loaders remain blocked.
- DigiRide real-package conversion/publication passed in an isolated VM fixture; Chronomon and Parallelmon riding and both costume replacements were confirmed together in live gameplay through the stable root.
